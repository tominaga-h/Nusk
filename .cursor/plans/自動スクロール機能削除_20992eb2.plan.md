# 日付グループ自動スクロール機能の削除

## 変更対象ファイル

### 1. [apps/web/composables/useTaskStore.ts](apps/web/composables/useTaskStore.ts)

- **`scrollToDateSection` 関数を削除** (L312-318)

```typescript
function scrollToDateSection(group: DateGroupKey) {
  nextTick(() => {
    document
      .getElementById(`date-section-${group}`)
      ?.scrollIntoView({ behavior: 'smooth', block: 'start' })
  })
}
```

- **`switchToDateView` 内のスクロール呼び出しを削除** (L329-331): 同じ日付ビュー/グループ選択済みの場合に `scrollToDateSection` を呼んで early return していた分岐を削除し、単純に「既に同じステートなら何もしない」だけにする。

変更前:

```typescript
if (viewMode.value === 'date' && selectedDateGroup.value === group) {
  scrollToDateSection(group)
  return
}
```

変更後:

```typescript
if (viewMode.value === 'date' && selectedDateGroup.value === group) return
```

- **return オブジェクトから `scrollToDateSection` を削除** (L419)

### 2. [apps/web/pages/tasks.vue](apps/web/pages/tasks.vue)

- **import から `scrollToDateSection` を削除** (L24)
- **route.query watcher 内のスクロール呼び出しを削除** (L37-39)

変更前:

```typescript
watch(() => route.query, (query) => {
  syncFromRoute(query as Record<string, string>)
  if (query.view === 'date') {
    scrollToDateSection((query.group as DateGroupKey) || 'today')
  }
}, { immediate: true })
```

変更後:

```typescript
watch(() => route.query, (query) => {
  syncFromRoute(query as Record<string, string>)
}, { immediate: true })
```

- `DateGroupKey` の import は `syncFromRoute` のパラメータ型としては直接使われていないため不要になる可能性があるが、`switchToDateView` が内部で使用しているため削除不要。

### 3. [apps/web/components/TaskDateSection.vue](apps/web/components/TaskDateSection.vue)

- `<section :id="'date-section-' + groupKey">` の `:id` バインディングはスクロールターゲット専用のため**削除**する (L36)。

## 変更しないもの

- `selectedDateGroup` ステートはサイドバーのアクティブ表示に使用されているため残す。
- `DateGroupKey` 型は複数箇所で使われているため残す。
