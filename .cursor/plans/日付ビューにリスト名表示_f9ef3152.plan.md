# 日付ビュー時のTaskItemにリスト名を表示

## 背景

日付ビューでは全リストのタスクが混在して表示されるため、各タスクがどのリストに属するかが分からない。各 `TaskItem` にリスト名のバッジを追加する。

## 現状の構造

- **Task 型**: `list_id` を持つが `list name` は持たない
- **lists**: task store に `lists: Ref<List[]>` として保持（`id`, `name` 等）
- **日付ビュー**: [TaskDateSection.vue](apps/web/components/TaskDateSection.vue) が `TaskItem` を描画
- **リストビュー**: [tasks.vue](apps/web/pages/tasks.vue) が `TaskItem` を直接描画（選択リスト内のタスクのみ）

## 実装方針

**prop 経由でリスト名を渡す方式**を採用する。TaskItem は表示用コンポーネントなので、ビューモードを意識させず、親が「リスト名を渡すかどうか」で表示制御する。

### 変更ファイルと内容

**1. [TaskItem.vue](apps/web/components/TaskItem.vue) に `listName` prop を追加**

- optional な `listName?: string` prop を追加
- `task-item__info` 内に、リスト名バッジを追加（`listName` が存在する場合のみ表示）
- ステータスバッジの前に配置し、どのリストのタスクかを一目で識別可能にする
- スタイル: 既存のステータスバッジに似た控えめなバッジ（背景: `border-light`, 文字色: `text-secondary`）

```vue
<!-- listName が渡された場合のみ表示（日付ビュー用） -->
<span v-if="listName" class="task-item__list-name">{{ listName }}</span>
```

**2. [TaskDateSection.vue](apps/web/components/TaskDateSection.vue) でリスト名を解決して渡す**

- task store の `lists` を取得
- `task.list_id` から `lists` 配列を検索してリスト名を取得し、`:list-name` prop として渡す

```vue
<TaskItem
  ...
  :list-name="lists.find(l => l.id === task.list_id)?.name ?? ''"
  ...
/>
```

**3. リストビュー（tasks.vue）は変更不要**

リストビューでは `listName` を渡さないため、リスト名は表示されない（選択中リスト内のタスクしか表示されないため不要）。
