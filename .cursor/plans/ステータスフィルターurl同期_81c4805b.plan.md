# ステータスフィルターのURLクエリパラメータ同期

## 概要

`statusFilter`（all / incomplete / done）をURLクエリ `?status=incomplete` として保持する。`/tasks` アクセス時はデフォルトで未完了タスクのみ表示する。

### URL設計（status追加後）

- `/tasks?view=list&list=xxx&status=incomplete` -- リストビュー、未完了
- `/tasks?view=date&group=today&status=all` -- 日付ビュー、全件
- `/tasks` -- デフォルト: リスト + Inbox + **incomplete**

## 変更対象ファイル

### 1. [useTaskStore.ts](apps/web/composables/useTaskStore.ts)

**statusFilter のデフォルト値変更** (L60):

```typescript
// before
const statusFilter = useState<'all' | 'incomplete' | 'done'>('status-filter', () => 'all')
// after
const statusFilter = useState<'all' | 'incomplete' | 'done'>('status-filter', () => 'incomplete')
```

**現在のクエリを保ったまま status だけ変更する関数を新設**:

```typescript
function switchStatusFilter(status: 'all' | 'incomplete' | 'done') {
  const route = useRoute()
  navigateTo({ path: '/tasks', query: { ...route.query, status } })
}
```

**switchToDateView / switchToListView に status を含める** (L320-338):

`navigateTo` の `query` に `status: statusFilter.value` を追加する。

```typescript
function switchToDateView(group: DateGroupKey = 'today') {
  if (viewMode.value === 'date' && selectedDateGroup.value === group) {
    scrollToDateSection(group)
    return
  }
  navigateTo({ path: '/tasks', query: { view: 'date', group, status: statusFilter.value } })
}

function switchToListView(listId: string) {
  if (viewMode.value === 'list' && selectedListId.value === listId) return
  navigateTo({ path: '/tasks', query: { view: 'list', list: listId, status: statusFilter.value } })
}
```

**syncFromRoute に status 復元を追加** (L346-356):

```typescript
function syncFromRoute(query: Record<string, string>) {
  // ...既存のview/list/group復元...
  const status = query.status as 'all' | 'incomplete' | 'done' | undefined
  statusFilter.value = status || 'incomplete'
}
```

**return に switchStatusFilter を追加**。

### 2. [TaskFilterBar.vue](apps/web/components/TaskFilterBar.vue)

`setStatusFilter` を直接の `statusFilter.value =` から、ストアの `switchStatusFilter` 呼び出しに変更する。

```typescript
// before
const { statusFilter } = useTaskStore()
function setStatusFilter(value: 'all' | 'incomplete' | 'done') {
  statusFilter.value = value
}

// after
const { statusFilter, switchStatusFilter } = useTaskStore()
```

テンプレートの `@click="setStatusFilter('all')"` 等を `@click="switchStatusFilter('all')"` に変更。

### 3. [tasks.vue](apps/web/pages/tasks.vue)

変更不要。既存の `watch(() => route.query, ...)` が `syncFromRoute` を呼び、そこで `statusFilter` が復元される。
