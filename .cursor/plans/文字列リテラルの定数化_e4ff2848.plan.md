# DateGroup / StatusFilter 文字列リテラルの定数参照への置き換え

## 背景

[types.ts](apps/web/composables/task-store/types.ts) で以下の定数オブジェクトが定義されているが、他ファイルでは文字列リテラル（`'today'`, `'incomplete'` 等）を直接使っている箇所が多い。

```typescript
export const DateGroup = {
  OVERDUE: 'overdue', TODAY: 'today', TOMORROW: 'tomorrow',
  UPCOMING: 'upcoming', UNDATED: 'undated',
} as const;

export const StatusFilter = {
  ALL: 'all', INCOMPLETE: 'incomplete', DONE: 'done',
} as const;
```

## 変更対象ファイルと内容

### 1. [state.ts](apps/web/composables/task-store/state.ts)（2箇所）

- import に `DateGroup`, `StatusFilter` の値インポートを追加
- L39: `() => 'incomplete'` → `() => StatusFilter.INCOMPLETE`
- L41: `() => 'today'` → `() => DateGroup.TODAY`

### 2. [navigation.ts](apps/web/composables/task-store/navigation.ts)（3箇所）

- import に `DateGroup`, `StatusFilter` の値インポートを追加
- L24: デフォルト引数 `= 'today'` → `= DateGroup.TODAY`
- L61: フォールバック `|| 'today'` → `|| DateGroup.TODAY`
- L70: フォールバック `|| 'incomplete'` → `|| StatusFilter.INCOMPLETE`

### 3. [filters.ts](apps/web/composables/task-store/filters.ts)（7箇所）

- import を `import { DateGroup, StatusFilter } from './types'` + `import type { DateGroupKey, TaskState } from './types'` に変更（`DateGroup` は値+型の両方で使えるため type import から外す）
- L34: `=== 'incomplete'` → `=== StatusFilter.INCOMPLETE`
- L40: `=== 'done'` → `=== StatusFilter.DONE`
- L91/96/101/106/111: `key: 'overdue' as DateGroupKey` 等 → `key: DateGroup.OVERDUE` 等（`as DateGroupKey` キャストも不要になる）

### 4. [TaskDateSection.vue](apps/web/components/TaskDateSection.vue)（2箇所）

- import に `import { DateGroup } from '~/composables/task-store/types'` を追加
- L29: `=== 'today'` → `=== DateGroup.TODAY`
- L32: `=== 'tomorrow'` → `=== DateGroup.TOMORROW`

### 5. [AppSidebar.vue](apps/web/components/AppSidebar.vue)（10箇所）

- import に `import { DateGroup } from '~/composables/task-store/types'` を追加
- テンプレート内の `selectedDateGroup === 'today'` / `switchToDateView('today')` 等、全5グループ分（比較 + 関数呼び出しで各2箇所 x 5グループ = 10箇所）を `DateGroup.TODAY` 等に置き換え

### 6. [TaskFilterBar.vue](apps/web/components/TaskFilterBar.vue)（6箇所）

- import に `import { StatusFilter } from '~/composables/task-store/types'` を追加
- テンプレート内の `statusFilter === 'all'` / `switchStatusFilter('all')` 等、全3フィルター分（比較 + 関数呼び出しで各2箇所 x 3値 = 6箇所）を `StatusFilter.ALL` 等に置き換え

## 注意点

- `DateGroup` は const オブジェクトとインターフェースで同名だが、TypeScript では値名前空間と型名前空間が分離しているため、通常の `import { DateGroup }` で値と型の両方が利用可能
- Vue 3 の `<script setup>` ではインポートした値は自動的にテンプレートで利用可能なため、追加のエクスポート処理は不要
