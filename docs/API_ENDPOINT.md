# Nusk API エンドポイント定義 (v1)

## 共通仕様

- **Base URL:** `/api/v1`
- **認証:** リクエストヘッダに `Authorization: Bearer <token>` を付与（CLI用のパーソナルアクセストークン、またはWebのSupabaseセッション）
- **リクエスト/レスポンス形式:** `application/json`

---

## リストの作成

- メソッド: POST
- エンドポイント: `/api/v1/lists`

**機能**
Web画面からの新規リスト作成で使用するエンドポイント。
`name` を受け取り、ログインユーザーに紐づくリストを作成する。
ユーザーの初回アクセス時などに Inbox リスト（`is_inbox: true`）が存在しない場合は、システム側で自動生成する。Inbox はユーザーごとに1つのみ存在し、このエンドポイントからは通常のリスト（`is_inbox: false`）のみ作成可能とする。

## リストの更新

- メソッド: PATCH
- エンドポイント: `/api/v1/lists/:id`

**機能**
リスト名の変更などに使用する部分更新エンドポイント。
Inbox リスト（`is_inbox: true`）の名前変更や削除は制限する。

## リスト一覧の取得

- メソッド: GET
- エンドポイント: `/api/v1/lists`

**機能**
ログインユーザーが所有するリストの一覧を取得するエンドポイント。
サイドバーのリスト表示や、タスク登録時のリスト選択UIで使用する。Inbox リストを含む全リストを返却する。

---

## ステータスの作成（グローバル）

- メソッド: POST
- エンドポイント: `/api/v1/statuses`

**機能**
全リスト共通で使用するグローバルステータスを作成するエンドポイント。
`name`（表示名）、`category`（`TODO` / `IN_PROGRESS` / `DONE` のいずれか）、`sort_order`（表示順）を受け取る。
ユーザー初回登録時にデフォルトのステータスセット（例: 未対応・対応中・完了）を一括登録する用途にも使用する。

## ステータスの作成（リスト固有）

- メソッド: POST
- エンドポイント: `/api/v1/lists/:list_id/statuses`

**機能**
指定したリストに固有のステータスを追加するエンドポイント。
`name`（表示名）、`category`（`TODO` / `IN_PROGRESS` / `DONE` のいずれか）、`sort_order`（表示順）を受け取る。
リスト固有のワークフロー（例: 「レビュー中」）が必要な場合に使用する。

## ステータスの更新

- メソッド: PATCH
- エンドポイント: `/api/v1/statuses/:id`

**機能**
ステータスの表示名（`name`）、カテゴリ（`category`）、並び順（`sort_order`）の部分更新エンドポイント。
グローバルステータス・リスト固有ステータスの両方に対応する。

## ステータス一覧の取得

- メソッド: GET
- エンドポイント: `/api/v1/statuses`

**機能**
ログインユーザーが所有するステータスの全件一覧を `sort_order` 昇順で取得するエンドポイント。
クエリパラメータ `?list_id=xxx` を指定した場合、そのリスト固有のステータスとグローバルステータス（`list_id` が NULL）の両方を返却する。
タスクのステータス変更UIや、リストごとのカンバン表示で使用する。

---

## タスクの登録

- メソッド: POST
- エンドポイント: `/api/v1/tasks`

**機能**
CLIからの `nusk add` やWeb画面からの新規作成で使用するエンドポイント。
リクエストのペイロードに `list_id` が未指定の場合は、API側で自動的に「Inbox（未整理）」のリストIDを割り当てる仕様とする。

## タスクの更新（論理削除含む）

- メソッド: PATCH
- エンドポイント: `/api/v1/tasks/:id`

**機能**
ステータス変更、着手日（`scheduled_date`）変更、メタデータ（`metadata`）の編集で使用する部分更新エンドポイント。
※物理削除（DELETE）はシステムとして廃止しているため、タスクの「削除」操作もこのエンドポイントを利用し、ステータスを「削除済み（アーカイブ）」等に変更する論理削除として扱う。

## タスク一覧の取得

- メソッド: GET
- エンドポイント: `/api/v1/tasks`

**機能**
Web画面の「リストView」や「日付View」を描画する際の一覧取得エンドポイント。
`?scheduled_date=YYYY-MM-DD` や `?list_id=xxx` などのクエリパラメータを付与することで、表示したい条件に合わせた柔軟なフィルタリングを行う。

## 特定タスクの詳細取得

- メソッド: GET
- エンドポイント: `/api/v1/tasks/:id`

**機能**
タスクの詳細画面（Webのドロワーやモーダル等）を開いた際や、CLIで特定タスクの詳細を確認する際のデータフェッチで使用するエンドポイント。JSONB型のメタデータを含む、該当タスクの全情報を取得する。
