# 画面フロー

## 1. LP

- ランディングページ

## 2. ログインページ

- GoogleまたはGithubによるログイン

## 3. 初期設定ページ

- リストやステータスの初期設定

## 4. タスク一覧ページ

### 4-1. リストビュー

- 3の初期設定で登録したリストをサイドバーに表示
- 該当するリストに登録されているタスクのみを表示
- タスクボックスに表示する項目:
  - タスク内容
  - ステータス
  - 期日
  - メタデータ
  - 「今日やる」ボタン（期日が今日の場合は非表示）
  - 「明日やる」ボタン

### 4-2. 日付ビュー（タイムライン/アジェンダ型）

- サイドバーのリストセクション先頭に「日付ビュー」項目を配置
- サイドバーの「今日」「明日」クリックでも日付ビューに切り替え
- タイトル: 「今後のタスク N件」
- リストを横断して、以下の4グループにタスクを分類表示:
  - **今日 (M月D日)**: scheduled_date が今日のタスク
  - **明日 (M月D日)**: scheduled_date が明日のタスク
  - **今週後半**: scheduled_date が明後日〜今週日曜のタスク
  - **未定**: scheduled_date が null のタスク
- 各グループは区切り線付きラベルで表示
- 空グループは「タスクはありません」を表示
- フィルターバーの「期限」ボタンは非表示（日付グルーピングで代替）
- タスクボックスに表示する項目:
  - タスク内容
  - ステータス
  - メタデータ
- ボタン表示ルール:
  - 今日グループ: 「今日やる」非表示、「明日やる」のみ
  - 明日グループ: 「明日やる」非表示、「今日やる」のみ
  - 今週後半/未定グループ: 両ボタン表示
