# 画面フロー

## 1. LP

- ランディングページ

## 2. ログインページ

- GoogleまたはGithubによるログイン

## 3. 初期設定ページ

- リストやステータスの初期設定

## 4. タスク一覧ページ

### 4-1. リストビュー

- 3の初期設定で登録したリストをサイドバーに表示
- 該当するリストに登録されているタスクのみを表示
- タスクボックスに表示する項目:
  - タスク内容
  - ステータス
  - 期日
  - メタデータ
  - 「今日やる」ボタン（期日が今日の場合は非表示）
  - 「明日やる」ボタン

### 4-2. 日付ビュー

- 今日と明日のリストをサイドバーに表示。
- 該当する日付が期日のタスクのみを表示（リスト関係ない）
- タスクボックスに表示する項目:
  - タスク内容
  - ステータス
  - リスト
  - メタデータ
  - 「今日やる」ボタン（期日が今日の場合は非表示）
  - 「明日やる」ボタン
