# 次世代タスク管理システム「Nusk」 要件定義書

## 1. プロジェクト概要

### 1.1. 背景と目的

既存のタスク管理ツール（Markdown、Notion、スマホアプリ、スプレッドシート等）における「手動移動の苦痛」「入力の摩擦」「リマインドの欠如」という課題を解決する。
エンジニアの思考とワークフローに最適化され、摩擦ゼロの入力と確実な実行をサポートする次世代のタスク管理システム「Nusk」を構築する。

### 1.2. コアコンセプト

- **APIファースト:** Nuxt上に構築したAPIをハブとし、多様なインターフェースから一元的にタスクを操作する。
- **爆速入力 (Capture):** 作業中のコンテキストを壊さず、CLIやWebから即座にタスクを登録できる。
- **柔軟な整理 (Process):** スプシライクな柔軟なメタデータと、リストごとの状態管理を実現する。
- **確実な実行 (Do):** スマホPWAへのプッシュ通知と、未完了タスクの自動リスケジュールで「忘れ」を防止する。

### 1.3. システムアーキテクチャ・技術スタック

- **プログラミング言語:** TypeScript (全レイヤーで型を完全共有)
- **フロントエンド & APIサーバー:** Nuxt.js (Vue.js) + Nitro
- **インフラ・デプロイ:** Vercel
- **データベース & 認証:** Supabase (PostgreSQL, Google OAuth)
- **CLIツール & ランタイム:** Bun
  - 採用理由: Node.js特有の起動ラグを排除し、CLIでの「0.1秒の爆速入力」を実現するため。また、Bun Workspacesを用いてプロジェクト全体のパッケージ管理とTypeScriptの型共有をシームレスに行う。

## 2. 構築物とディレクトリ構成

本プロジェクトは、Bun Workspacesを利用したモノレポ構成とする。WebとCLIでタスクの型定義（Interface）などを完全に共有し、開発体験（DX）と保守性を極限まで高める。

```txt
[ディレクトリ構成]
nusk/
├── package.json      （Bun Workspacesのルート設定: "workspaces": ["apps/*", "packages/*"]）
├── apps/             （アプリケーション群）
│   ├── web/          （Nuxt.jsプロジェクト: フロントエンド + API。Vercelへデプロイ）
│   └── cli/          （Bun + TypeScript: ターミナル用CLIツール。コマンド名: nusk）
└── packages/         （共有パッケージ群）
    ├── shared/       （TypeScript型定義や共通ロジック。webとcliから参照）
    ├── ui/           （必要に応じて: 共通UIコンポーネント）
    └── config/       （必要に応じて: 共通のESLint/TSConfig設定など）
```

## 3. Webサイト（PWA）の要件

### 3.1. タスク操作・管理（CRUD）機能

- Web画面上からタスクの新規登録、編集、論理削除、ステータス変更がスムーズに行えること。
- Inbox（未整理）に溜まったタスクを適切なリストへ振り分け、メタデータを付与できること。

### 3.2. タスク閲覧・UI機能

- **リストView:** プロジェクトやカテゴリごとにタスクを一覧表示する。
- **日付View:** `scheduled_date` (着手予定日) に基づいてタスクを表示し、「今日やること」に集中できる。
- **ワンタップ着手日変更:** UI上の「今日やる」「明日やる」ボタンで着手日を即座に更新できる。

### 3.3. タスクの状態・メタデータ管理

- **状態 (Status) のリスト単位管理:** 「未対応」「対応中」「完了」などの状態は、リスト（箱）ごとに自由に定義・変更できる。
- **拡張メタデータ:** ユーザーが自由に拡張したい項目（タグ、重要度等）はDBの `JSONB` カラムに保存し、Web UIから柔軟に追加・編集可能とする。

### 3.4. 自動化・リマインド機能

- **自動リスケジュール (Overdue処理):** 未完了のまま過去の日付になったタスクは、自動的に「今日 (Today)」にリスケジュールされる。
- **繰り返しタスクのクローン生成:** 繰り返しルールが設定されたタスクが完了した際、次回の期日がセットされた新しいタスクを自動生成する。
- **プッシュ通知:** 設定されたリマインド時間に基づき、PWAを通じてスマホへWeb Push通知を送信する。

### 3.5. システム・設定機能

- Supabaseを通じたGoogle OAuthでのログイン。
- CLIツールからAPIを利用するための「パーソナルアクセストークン」発行・管理。

## 4. CLIツールの要件

### 4.1. 爆速タスク入力機能

- ターミナルから `nusk add "タスク名"` を実行し、API経由で「Inbox」リストにタスクを即座に登録する。
- 引数なしで `nusk add` を実行した場合、環境変数 `$EDITOR` が起動し、保存と同時に登録される。
- Bunランタイムの高速起動を活かし、コマンド実行から完了までのレスポンスは0.1秒以内を目指す。

### 4.2. API連携と型共有

- Webサイト側で発行したアクセストークンを使用し、Nuxt APIを安全に呼び出す。
- APIリクエスト/レスポンスのデータ構造は `shared/` のTypeScript型定義を流用し、安全な実装を担保する。
